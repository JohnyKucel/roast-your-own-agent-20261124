## The roast

> My agent treats every simple task like a trilogy: a beginning, a middle, and a sequel nobody asked for.

## How it works

`main.py` (Python stdlib only, no network, no secrets) brainstorms six fresh roast lines, grades each one on funniness, freshness and tight wording, and writes the winning line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

Winner: 37 points, 103 characters, single line — inside the 1–200 character gate.
